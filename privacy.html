プライバシーポリシー

最終更新日: 2026年9月26日

1. 対象

本アプリは、開発者本人が個人的に利用するための自動化ツールです。開発者本人以外の利用は想定していません。

2. 取得する情報

本アプリは Google API を通じて、利用者本人の許可した範囲で次の情報にアクセスします。

  • Gmail: 不動産ポータルサイトから届く新着物件通知メールの読み取り、および処理済みを示すラベルの付与
  • YouTube: 本人のチャンネルへの動画アップロードと統計情報の取得

3. 利用目的

取得した情報は、利用者本人のパソコン上で物件情報の整理や動画投稿の補助に使用するためだけに利用します。

4. 保存と第三者提供

  • 取得した情報は利用者本人のパソコン内にのみ保存し、外部サーバーには送信しません。
  • 取得した情報を第三者に提供・販売することはありません。
  • Google API から取得した情報の利用は、Google API Services User Data Policy(Limited Use 要件を含む)に従います。

5. アクセス権の取り消し

本アプリへのアクセス許可は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。
